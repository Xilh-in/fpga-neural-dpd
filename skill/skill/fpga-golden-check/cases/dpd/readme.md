# DPD 定点核对回归案例

这是本项目特例，不是通用算法模板。参数数量/排列、位宽和 +1 偏移只在本案例有效。

来源：2026-10-26 合作方提供的 v1_1026.zip。input 内三份 CSV 保持字节不变。参数文件在整理时仅将 CRLF 换行统一为 LF，576 项参数数值保持不变；input_manifest.json 记录整理后文件的 SHA-256。reference_model.py 提取自项目离线分析器的计算函数，采用当时附件 dpd_ip_v1 的逐级运算规则，不依赖本队原始源码路径。

`replay_case.py` 重新计算各层，导出 reference.csv，再调用本技能的通用比较器。有效区间为实测 `[23,999)`；参考中心为实测编号 +1。976 点、1952 个标量精确一致；16 个 Q 路饱和均有截断前越界证据，L2 第 5 分支另有 58 次饱和。前 23、末 25 点没有完整采集上下文，不计为验证通过。

本地 RTL 仿真曾在生成 C 的编译阶段失败；本案例不附带或宣称成功的 RTL 仿真。它证明的是本批合作方实测与参考的数值一致，不证明全输入功能、性能或板卡移植。
