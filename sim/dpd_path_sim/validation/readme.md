# 交付前验证记录

修改版由 Verilator 执行真实 RTL 通路，18,520 项检查全部通过。另用 Python 对输出 CSV 独立复核，模型同采样对齐、最终相减及 1024 点采集均为 0 LSB 误差。

原始未修改 data_ctrl.v 的反向验证在同一套检查逻辑下失败，得到 10,256 项不匹配，可检出相减使用了相邻采样的模型输出。反向验证之后只对 TB 的 CSV 数值打印增加了显式符号扩展；检查逻辑未变，修改版及 CSV 复核使用最终 TB。
