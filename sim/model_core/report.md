# 模型输出 16 个限幅点核对报告

核对日期：2026-10-26。材料：v1_1026.zip 内三份 1024 点 CSV、model_0216_0.json 和随包 dpd_ip_v1 RTL。此次为离线核对，没有修改 PL、参数或板卡配置。

## 结论

**16 个点全部符合当前 RTL 的定点饱和规则。** 它们全在 Q 路，均被钳位到 -32768。按实际参数排列、缩放、CORDIC、逐级右移截位和饱和重建 Python 参考后，采集样本 23～998 的 976 点（I/Q 共 1952 个数）与实测逐个完全相同，最大误差 0 LSB。16 个限幅点全部在这个可严格核对的区间内。

同时需要区分：这证明了当前定点实现与本次实测一致，不能据此认定浮点模型没有数值损失。**第 5 个非线性分支（RTL 索引 4）已经出现 58 次中间层限幅**，且模型输出与 tx_delay 之间有 1 个采样的参考中心偏移。

## 参数、归一化和定点格式

模型 JSON 的 576 个整数与 B 之前交付的 examples/model_0216_0.json 数值逐项相同。直接按整数装载，不再次定点化、不改变顺序。输入 IQ 作为有符号 16 位整数，浮点含义为整数 / 32768；没有按每段数据的最大值重新归一化。

| 层或参数 | 数组布局 / 数据含义 | 小数位数 |
|---|---|---|
| 输入与最终输出 | I/Q 各 16 位，范围 [-1, 1) | 15 |
| 参数 0～307 | 7 组：21 个实部权重、实部偏置、21 个虚部权重、虚部偏置 | 13 |
| 参数 308～559 | 7 组：9 center、9 theta、9 实部权重、9 虚部权重 | theta=12，其余=13 |
| 参数 560～575 | 7 对 L3 实/虚权重，最后一对实/虚偏置 | 13 |
| L1 输出 | 16 位有符号，范围 [-4, 4) | 13 |
| L2 输出 | 16 位有符号，范围 [-2, 2) | 14 |

L1 使用 21 抽头、间隔 2 的居中复卷积，窗口覆盖中心前后各 20 点。cnn0_1d.v 的抽头反排与输入延迟组合后，对应原 Python 训练代码的互相关方向，不需要再翻转参数。

L2 第 j 项使用 `L1[n+j-4]` 的实部/虚部与各自权重相乘，径向系数取中心 n 的幅度：`exp(-abs(theta[j]) * (abs(L1[n])-center[j])^2)`。参考保留了这 9 个不同时间位置，没有简化为对同一个 L1 样本重复相乘。定点参考使用源码内的 CORDIC 常数和迭代，而非直接用浮点 abs/exp 代替。

参数映射依据：expcnn.sv 的 L1/L2/L3 位段（约 52～57 行），cnn0_1d.v 的 87～94 行，nl_core.v 的 114～117、494～495 行，linear_layer_1.sv 的 50～52 行。

## 流水线与三份 CSV 的对应关系

三份 CSV 全部 1024 点满足 **tx_final[n] = tx_delay[n] - model_out[n]**，两个分量都没有误差，本批差值也未触发最终输出再次限幅。由此未发现三份采集数据之间的整体错行。

但 Python 的居中模型参考必须按 **model_out[n] = fixed_reference(tx_delay)[n+1]** 比较。按同一行直接比较会产生约 2825.717 LSB 的定点 RMSE；加上该 1 点偏移后，整个可核对区间变为 0 LSB。不要把它误判为参数次序或字节序错误。

RTL 结构也支持该相对关系：align.v 第 117 行固定取 delay_data_x[65]；居中卷积窗口、模型各层和接口寄存器合计的采样边沿编号差推导为 64。这里以原始输入样本在边沿 t 被采样为基准，模型中心结果约在 t+64、纯延迟流约在 t+65；“65T”注释与从 0 起的边沿编号不能直接混用。数据精确匹配支持相对差 1 点，独立仿真确认仍待 A 在可用工具环境完成。

这也意味着当前直通减模型的两路在“训练模型中心样本”的意义上有 1 点差异。是否保留该设计或补偿这 1 拍，应由 A 根据当前实现和仿真记录确认；此次没有擅自改动延迟寄存器。

由于只有一段 1024 点输入，L1 的 +/-20 点上下文加 L2 的 +/-4 点上下文要求参考中心处于 24～999。再结合 +1 的对齐量，对实测只能严格比较编号 23～998；前 23 点和末 25 点不作正确性断言。所有 16 个限幅点都有完整上下文。

## 与理想浮点模型的差别

在上述同一可比窗口中：

| 节点 | 限幅情况 |
|---|---|
| L1 | 0 次 |
| L2 的乘权/单项乘径向系数节点 | 未发现限幅 |
| L2 最终输出 | 第 5 分支 I 18 次、Q 40 次，共 58 次，其余分支 0 次 |
| L3 最终输出 | I 0 次、Q 16 次，正是本次 16 点 |

L2 的 58 次饱和来自 nl_core.v 第 435～460 行：取 y_out[24:9] 后压到 16 位，范围只有 [-2, 2)。这会改变后续 L3 组合结果，所以不能只跑无中间限幅的浮点网络，再在最末尾 clip 一次，就断言板上算错。

使用同一量化参数解码后的理想浮点模型，只在最末尾限幅时，I/Q 总计会出现 10/26 个越界分量，与实测的 0/16 不同；末尾限幅后的浮点结果与实测 RMSE 约 1242.980 LSB。作为定位用的对照实验，仅取消参考中的 L2 最后一次饱和，保留其余 CORDIC、定点截位，再与理想浮点的未限幅输出比较，RMSE 仅约 1.649 LSB。这说明本批浮点/定点差异主要来自 L2 输出饱和，而不是参数顺序或输入多乘了某个归一化系数。

因此：**本次 16 点是当前 RTL 的预期结果；若要求贴近训练浮点模型，应另行评估 L2 动态范围与后续缩放。** 直接取消 L3 限幅不能解决中间层数值损失，也不应在本轮诊断中直接改写参数。
